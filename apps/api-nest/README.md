# Rangon API — NestJS

The Rangon API on NestJS 11 (Fastify) with Drizzle over `pg`, served beside the Django API from the
same database and proven to answer as it does. Django owns the schema; this reads it.

- Why, and the rules it follows: [ADR-0013](../../docs/architecture/decisions/0013-nestjs-api-alongside-django.md)
- What is ported, how to port the next module, measured performance:
  [docs/architecture/nest-port.md](../../docs/architecture/nest-port.md)

```text
src/
  main.ts, app.module.ts     bootstrap: Fastify, the Django middleware order, guards, the error filter
  config/                    environment, validated at startup, Django's variable names
  http/                      middleware as Fastify hooks; route registry for 404/405
  auth/                      SimpleJWT-compatible tokens, authentication guard, rate limits
  common/                    Python/DRF compatibility: parsing, pagination, datetimes, decimals, errors
  database/                  pg pool, Drizzle schema (generated by `npm run db:pull`, never migrated)
  accounts/ catalog/ content/ inventory/   services, one per Django app
  shop/                      the storefront's controllers
parity/                      the harness comparing both APIs, its fixtures, the benchmark
test/unit/                   unit tests
```

Node is not required on the host; every command runs in `node:22-bookworm-slim`, for example:

```bash
docker run --rm --user "$(id -u):$(id -g)" -e HOME=/tmp -v "$PWD":/app -w /app node:22-bookworm-slim npm test
```
